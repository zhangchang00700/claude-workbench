# ClaudeWorkbench v0.2.0

> 本迭代主题：**随手唤起、并行推进、自动更新**。

## 新增

### 1. 全局热键速聊条（ClaudeBot 入口）

- 任意界面按全局热键唤起速聊条，无需切回主窗口；答完即走，不落进会话列表。
- 默认 `Alt+Space`。**Windows 上 `Alt+Space` 是系统窗口菜单的保留键，大概率注册不上**——此时自动降级到 `Ctrl+Alt+Space`，再不行 `Alt+Shift+Space`。实际生效的键位会显示在速聊条空态和主窗口「⚡ 速聊」按钮上，以那里为准。
- 三个热键都不可用时，点主窗口「⚡ 速聊」按钮或托盘菜单「速聊」项照样唤起。
- `Esc` 收起，失焦也收起；答完想接着聊，点「↩ 投送到完整会话」——会把问答原样转成一个正式会话（问题+答案都在），并在主窗口自动打开。
- 速聊**不起 claude CLI**（冷启动太慢），直连本地模型路由站，因此秒开秒答，自动继承路由站的故障转移与熔断。

### 2. 多会话并行（页签）

- 会话以 tab 形式并列，可同时开多个并行推进；各 tab 草稿独立，切走再切回内容不丢。
- 后台会话继续跑，tab 上有呼吸点表示进行中；跑完切回来能看到完整结果。
- 关闭 tab 只收起，不删会话数据（会话记录、项目分组、归档都不受影响）。

### 3. 自动更新检测与下载

- 设置页/状态栏可手动检查更新：有新版本时显示版本号、更新说明、安装包大小，可一键下载。
- 下载走 GitHub API 通道（本机网络只放行 api.github.com 的场景下也能用），带真实进度；完成后直接打开所在文件夹。
- 下载完成后校验文件大小与发布页登记值一致，缺一字节即提示「下载不完整」，不会给你一个打不开的坏包。
- **本版不做静默自替换**（自动替换要处理文件占用，风险高，排后续版本）：下载后请手动覆盖旧版。

## 交付形态

Windows x64 便携版，解压即用，无需安装：

- `ClaudeWorkbench-0.2.0-win.zip` —— 便携压缩包
- `ClaudeWorkbench-0.2.0-win.exe` —— 便携 exe

## 升级说明

便携版直接覆盖解压即可；旧版配置（API Key、供应商设置）、会话数据、项目分组全部保留在 `%APPDATA%\ClaudeWorkbench`，不受影响。

## 已知限制

- 仅 Windows x64。
- 主窗口对话依赖本机 claude CLI；**速聊条不依赖 CLI**，只要配置了可用供应商（API Key）即可。
- 自动更新检测需要本机有 `gh` CLI 且已认证（`gh auth login`），或网络可达 GitHub API；不满足时给出明确原因，不影响其它功能。
