# ClaudeWorkbench v0.1.1

> 首个公开发布快照。AI 工业化工作台：claude CLI 内核 + Electron 便携单文件。

## 已有能力

- **对话工作台**：以 claude CLI 为内核的会话界面，流式输出、Markdown 渲染、代码高亮。
- **任务队列 / 模板流水线**：把重复工作固化成模板，排队执行。
- **定时自动化**：cron 表达式驱动的定时任务。
- **用量与成本看板**：token 消耗与成本可视。
- **桌宠**：桌面陪伴组件。

## 交付形态

Windows x64 便携单文件，解压即用，无需安装：

- `ClaudeWorkbench-0.1.1-win.zip` —— 便携压缩包
- `ClaudeWorkbench-0.1.1-win.exe` —— 便携 exe

## 已知限制

- 仅 Windows x64。
- 需本机已配置可用的 claude CLI 运行环境。
