# ClaudeWorkbench v0.2.1

> 本迭代主题：**稳态修复、体验加速、一键安装**。

## 修复

### 1. 并发写入竞态修复

- 修复多会话并行时会话数据写入的竞态条件，消除偶发的记录丢失或覆盖问题。
- 对会话存储层增加写入串行化保护，确保并发场景下数据一致性。

## 优化

### 2. 速聊窗预热

- 应用启动后静默**预创建速聊窗**（不显示），首次唤起从「新建窗口+加载页面」降为「显示+聚焦」，消除冷启动延迟（实测预热 295ms，唤起即时）。
- 预热在 app ready 后进行，不阻塞主窗口；预热失败自动退化为冷路径，不影响功能。

## 新增

### 3. 一键安装更新

- 自动更新下载完成后支持一键安装替换，无需手动解压覆盖。
- 点击安装后应用自动退出，替换脚本等进程完全退出后解压覆盖旧版（校验安装包存在且大小正确），再自动重启——全程不杀任何进程。
- 配置与会话数据保存在 `%APPDATA%\ClaudeWorkbench`，不受覆盖安装影响；兼容原有手动覆盖升级路径。

**更新面板交互（下载完成后）**：

- 「打开所在文件夹」旁新增主按钮「一键安装并重启」。
- 按钮上方常驻 inline 确认文案（非弹窗）：「将退出 ClaudeWorkbench 并覆盖安装（配置与会话数据不受影响），安装后自动重启」，点击前即可见。
- 点击后按钮变「正在退出…」并禁用，同时显示「正在安装更新，应用即将重启…」；应用退出覆盖安装后自动重启；安装失败时面板内显示具体原因、按钮恢复可重试。
- 兜底：点击 5 秒仍未关窗（退出超时）时提示「退出超时，请手动关闭应用窗口，安装脚本将自动完成替换并重启」，手动关窗后安装脚本仍会接管替换并重启（等待窗口退出的上限为 120 秒）。
- 主进程未提供 `updateInstall` 通道时降级提示手动安装，不静默失败。

## 交付形态

Windows x64 便携版，解压即用，无需安装：

- `ClaudeWorkbench-0.2.1-win.zip` —— 便携压缩包
- `ClaudeWorkbench-0.2.1-win.exe` —— 便携 exe

## 升级说明

便携版直接覆盖解压即可；旧版配置（API Key、供应商设置）、会话数据、项目分组全部保留在 `%APPDATA%\ClaudeWorkbench`，不受影响。支持从 v0.2.0 一键安装升级。

## 已知限制

- 仅 Windows x64。
- 主窗口对话依赖本机 claude CLI；速聊条不依赖 CLI，只要配置了可用供应商（API Key）即可。
- 自动更新检测需要本机有 `gh` CLI 且已认证（`gh auth login`），或网络可达 GitHub API；不满足时给出明确原因，不影响其它功能。
