# 预设库扩充调研报告（2026-10-17）

> 调研对象：面向 claude-workbench 模型路由应用的内置供应商预设库扩充。
> 应用场景：转发 Claude CLI 的 `/v1/messages` 请求到多家上游，因此**是否有 Anthropic 兼容端点**是核心筛选维度。
> 调研方法：全部经 WebSearch / WebFetch 核对官方文档；查不到的信息明确标注「未找到」，未编造任何模型 ID 或 URL。
> 已有 6 家预设（智谱 GLM / DeepSeek / Kimi / Agnes / 火山方舟 / 阶跃星辰）不在本报告重复调研范围内。

## 0. 结论速览：推荐优先接入的 5 家

| 排序 | 供应商 | 推荐理由（一句话） |
|---|---|---|
| 1 | **魔搭 ModelScope** | 注册用户完全免费（2000 次/日）+ 国内直连 + 官方提供 Anthropic 兼容端点（beta），阿里官方运营，零成本试错 |
| 2 | **MiniMax** | 官方 Anthropic 兼容端点且被官方标注为推荐接入方式，M3 编码能力强、1M 上下文，国内站 `api.minimaxi.com` 人民币计费 |
| 3 | **TokenHub（腾讯云）** | 腾讯官方聚合产品，OpenAI + Anthropic 双协议同一 Base URL，提供 `GET /v1/models`，官方自带 Claude Code / WorkBuddy 接入指南 |
| 4 | **硅基流动 SiliconFlow** | 开源模型目录最全（200+），提供 `GET /models`，注册赠 14 元额度，Continue/Cline 等生态接入文档齐全 |
| 5 | **AiHubMix** | 少数同时提供 Claude 原生 `/v1/messages` 且带 27+ 个 `*-free` 免费模型的聚合站，提供 `GET /v1/models`；注意其为美国注册主体 |

备选说明：
- **阿里云百炼**：官方最稳、新用户每模型约 100 万 token 免费额度（90 天），但无 Anthropic 端点，需要应用侧做协议转换，且 base_url 涉及 WorkspaceId，适合作为 openai 协议 preset 补充。
- **七牛云**：OpenAI + Anthropic 双协议 + `/v1/models` + 新用户赠 300 万 Token，但需实名认证，可作第 6 家备选。
- **腾讯混元**：官方已公告能力逐步迁移至 TokenHub，原平台不再新增模型，不建议新投入，优先用 TokenHub 替代。

## 1. 协议与字段约定（供预设草案落地参考）

- `protocol = "anthropic"` 时，`baseUrl` 按 **Anthropic SDK 约定**填写（SDK 会请求 `{baseUrl}/v1/messages`）。
- `protocol = "openai"` 时，`baseUrl` 按 **OpenAI SDK 约定**填写（SDK 会请求 `{baseUrl}/chat/completions`）；此类上游需要路由应用自行完成 Anthropic → OpenAI 协议转换。
- 「自动获取模型」能力依赖各家的模型列表 API，下文逐家标注。

## 4. 推荐接入顺序与落地建议

1. **第一批（协议原生 + 国内直连）**：魔搭 ModelScope、MiniMax、TokenHub（腾讯云）。三家都有 Anthropic 原生端点，Claude CLI 请求可零转换直送；且都有明确的官方 Claude Code 接入文档。

3. **第三批（openai 协议补充）**：阿里云百炼、七牛云、OpenRouter、腾讯混元、讯飞星火、零一万物、NuwaAPI。按需开启，其中 NuwaAPI 因反代性质建议默认关闭或标注风险。
